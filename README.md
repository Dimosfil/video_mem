# YouTube Downloader

## Telegram Video Clip MVP

Telegram-бот принимает ссылку на отдельное видео YouTube, спрашивает таймкоды начала и конца, показывает кнопку подтверждения, вырезает выбранный диапазон и возвращает MP4 в тот же чат. Для MVP не нужен сайт, домен или публичный HTTPS URL.

Подготовка:

```powershell
Copy-Item .env.bot.example .env
```

В `.env` укажите:

```text
TELEGRAM_POLLING_ENABLED=true
TELEGRAM_BOT_TOKEN=replace-with-real-token
```

Запуск:

```powershell
.\start-bot.ps1
```

Запуск в Docker:

```powershell
docker compose up -d --build
docker compose ps
docker compose logs --tail 100 video-clip-bot
```

Compose читает тот же игнорируемый `.env`, автоматически перезапускает бота и сохраняет задания в `./data`. Без `.env` контейнер можно собрать и проверить, но polling останется выключенным. Порты не публикуются: бот получает события Telegram через long polling. Остановка:

```powershell
docker compose down
```

Сценарий в чате:

1. Отправьте ссылку YouTube.
2. Отправьте начало фрагмента, например `01:20`.
3. Отправьте конец, например `02:05`.
4. Нажмите `Получить видео`.
5. Дождитесь готового MP4 в чате.

Ограничения MVP:

- одна ссылка и один фрагмент на задание;
- только отдельные видео YouTube, без плейлистов;
- максимальная длина по умолчанию — 180 секунд;
- результат нормализуется в MP4 с H.264/AAC и `faststart`;
- лимит отправки по умолчанию — 50 МБ;
- задания и временные файлы хранятся в игнорируемом `data/video-bot/` и удаляются по TTL;
- закрытые видео можно обрабатывать через Netscape cookies-файл, заданный в `YTDLP_COOKIE_FILE`.

Для cookies в Docker положите файл внутрь `./data` и укажите контейнерный путь, например `YTDLP_COOKIE_FILE=/app/data/youtube-cookies.txt`.

Минимальное desktop-приложение для Windows: вставить ссылку на YouTube, получить доступные качества и скачать ролик в выбранную папку. По умолчанию файлы сохраняются в `downloads/` рядом с `app.py`.

Используйте только для контента, на скачивание которого у вас есть права или разрешение.

Проверенный стек и команды: [`tools/project-memory/specs/technology-stack.md`](tools/project-memory/specs/technology-stack.md).

## Запуск

```powershell
.\start.ps1
```

Скрипт создаст локальное окружение `.venv`, установит зависимости из `requirements.txt` и откроет окно приложения.
Для YouTube также нужен JavaScript runtime; на этой машине найден Node.js, приложение включает его автоматически для `yt-dlp`.

## Ручная установка

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\python .\app.py
```

## Проверка

```powershell
.\.venv\Scripts\python -m unittest discover -s tests
```

## Примечание про качество

YouTube часто отдаёт высокие качества отдельными видео- и аудиодорожками. Если в системе установлен FFmpeg, приложение покажет и скачает такие варианты с автоматическим объединением. Без FFmpeg используются только селекторы одного готового файла, не требующие объединения потоков.

Для совместимости с обычным проигрывателем Windows приложение предпочитает MP4 с H.264-видео и M4A/AAC-аудио, а не AV1/Opus.

Скачанные файлы получают выбранное качество в имени, например `Название [1080p].mp4` или `Название [best].mp4`.

## Если YouTube просит вход

По умолчанию приложение не читает cookies браузера. Если появляется ошибка `Sign in to confirm you’re not a bot`, выберите в поле `Cookies` браузер, где вы уже вошли в YouTube. На Windows надёжнее всего сначала попробовать `Firefox`.

Если Chromium-браузер (`Edge`, `Chrome`, `Brave`) показывает `Could not copy ... cookie database` или `Failed to decrypt with DPAPI`, полностью закройте выбранный браузер и повторите. Если не помогает, нажмите `Файл...` и укажите экспортированный cookies-файл в формате Netscape. Это обходит блокировку/шифрование cookies браузером.

Если вход в YouTube сделан не в основном профиле Chrome, укажите имя профиля в поле `Профиль Chrome/браузера`, например `Default` или `Profile 1`.

После изменения ссылки, браузера, профиля или cookies-файла запросите список качеств заново. Приложение не разрешает использовать качества, полученные для предыдущих настроек.
