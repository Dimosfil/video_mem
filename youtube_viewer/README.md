# YouTube Viewer

Отдельное нативное Windows-приложение на .NET 8, WPF и Microsoft Edge WebView2 для просмотра YouTube.

В нём нет `yt-dlp`, выбора качества или функции скачивания. Загрузки в WebView явно отключены.

Маршрут подключения выбирается в настройках по кнопке `⚙`:

- «Системное подключение / общий VPN» — режим по умолчанию без привязки к конкретной VPN-программе. Подходит для обычного интернета, другого VPN или режима, где через VPN идут все приложения.
- «Локальный HTTP-прокси» — для раздельной маршрутизации через любой VPN-клиент, который предоставляет HTTP-прокси. Адрес задаётся пользователем; значение по умолчанию — `http://127.0.0.1:10809`.

В режиме локального прокси QUIC отключён, чтобы WebView2 не создавал прямой UDP-маршрут. Если выбранный прокси недоступен, приложение не переключается на прямое соединение и предлагает изменить настройки.

## Возможности

- Встроенный uBlock Origin Lite: блокировка рекламных запросов и рекламных элементов YouTube включена по умолчанию. Кнопка «Блокировка: вкл/выкл» переключает защиту во всех вкладках и обновляет текущую страницу; другие открытые страницы при необходимости обновите вручную. При ошибке запуска отображается «Блокировка: !» с пояснением в подсказке.
- Настоящие вкладки с добавлением, закрытием и восстановлением.
- Кнопка «+» справа от вкладок открывает YouTube в новой вкладке; при переполнении полоса вкладок прокручивается, а кнопка остаётся доступной.
- «Дублировать вкладку» в меню по правой кнопке открывает текущий адрес этой вкладки в отдельной активной вкладке сразу справа. История переходов и точная позиция видео не копируются.
- Автоматическое сохранение открытых вкладок, их названий, порядка и выбранной вкладки между запусками и обновлениями. Закрытие окна сохраняет сеанс; явно закрытые вкладки при запуске не возвращаются.
- При восстановлении сначала загружается выбранная вкладка, остальные — при первом переключении. Сохранённые названия видны сразу; для вкладок из старого сеанса без названий до загрузки показывается адрес сайта. Полный URL доступен в подсказке вкладки.
- Если основной документ не готов за 30 секунд или соединение завершилось ошибкой, появляется сообщение с кнопками повторной загрузки и настроек подключения. Уже открытая страница не прерывается из-за медленных картинок и других вспомогательных ресурсов. Ошибка фоновой вкладки не перекрывает текущую страницу.
- Перетаскивание вкладок мышью: отпустите вкладку на левой или правой половине другой вкладки, чтобы поставить её до или после неё.
- Меню по правой кнопке на вкладке: закрыть текущую, остальные, слева, справа или все; восстановить закрытую. Команды относятся к вкладке под указателем. Закрытие всех вкладок завершает приложение.
- Кнопки «Назад», «Вперёд», «Обновить» и «Домой».
- Адресная строка: URL открываются напрямую, обычный текст ищется на YouTube.
- Ссылки, запрашивающие новое окно, открываются в новой вкладке.
- Индикатор загрузки и полноэкранный режим.
- Видимые превью YouTube автоматически повторяют загрузку после ошибки или зависания более 20 секунд, максимум два раза. Позиция прокрутки сохраняется; постоянный сетевой сбой может потребовать проверки подключения.
- Контекстное меню и масштабирование WebView2 сохранены; скачивания отключены.
- Настройки подключения сохраняются отдельно от сборки и применяются после автоматического перезапуска.

Горячие клавиши:

| Клавиши | Действие |
| --- | --- |
| `F5`, `Ctrl+R` | Обновить страницу |
| `Ctrl+Shift+R` | Очистить браузерный кэш и обновить |
| `Alt+←`, `Alt+→` | Назад и вперёд |
| `Ctrl+T`, `Ctrl+W` | Открыть и закрыть вкладку |
| `Ctrl+Shift+T` | Вернуть закрытую вкладку |
| `Ctrl+Tab`, `Ctrl+Shift+Tab` | Переключить вкладку |
| `Ctrl+L` | Перейти в адресную строку |
| `Esc` | Остановить загрузку |
| `F11` | Полноэкранный режим |

## Запуск

Из корня проекта:

```powershell
.\youtube_viewer\start.ps1
```

Первый запуск соберёт отдельный `YouTube Viewer.exe`. Для работы нужны .NET 8 Desktop Runtime и Microsoft Edge WebView2 Runtime. Обычный запуск не использует Python и не открывает консоль.

Сессия WebView и `settings.json` хранятся в постоянном каталоге `%LOCALAPPDATA%\VideoMem\YouTubeViewer`, вне `dist`. Пересборка, замена и повторная установка EXE этот каталог не удаляют, поэтому cookies, авторизация YouTube и выбранный способ подключения сохраняются. Для выхода из аккаунта или полного сброса профиля этот каталог нужно удалить отдельно вручную.

Список открытых адресов, названия вкладок и выбранная вкладка автоматически записываются в `session.json` в том же каталоге; предыдущая исправная запись остаётся в `session.json.bak`. Изменения сохраняются по ходу работы и перед закрытием окна. Повторный запуск новой версии переключает на уже открытое окно, чтобы две копии не перезаписывали сеанс. Эта защита действует между версиями, которые уже поддерживают сохранение сеанса.

Версии без `session.json` не сохраняли список вкладок: ранее потерянные вкладки автоматически восстановить из такого сеанса нельзя. Восстановление открывает сохранённые адреса; история переходов внутри вкладки и точная позиция воспроизведения не сохраняются.

## Сборка

```powershell
.\youtube_viewer\build.ps1
```

Артефакт: `youtube_viewer/dist/YouTube Viewer/YouTube Viewer.exe`. Сборка имеет собственные имя процесса, Windows version resource, AppUserModelID и иконку. Восстановление NuGet выполняется по `packages.lock.json`. Папки `bin/`, `obj/`, `build/`, `dist/` и генерируемые иконки не попадают в Git.

## Установщик Windows

```powershell
.\packaging\windows\build.ps1
```

Готовый установщик: `youtube_viewer/dist/installer/YouTube-Viewer-Setup-1.3.6.exe`. Версия имени файла автоматически берётся из `YouTubeViewer.csproj`.

Установщик собирается через Inno Setup 6, устанавливает приложение для текущего пользователя без прав администратора и создаёт ярлык в меню «Пуск». Ярлык рабочего стола доступен как необязательная задача. В установочный пакет входит .NET 8 Desktop Runtime; отдельно требуется только Microsoft Edge WebView2 Runtime, который обычно уже установлен вместе с Windows или Microsoft Edge.

Обновление и удаление приложения не затрагивают `%LOCALAPPDATA%\VideoMem\YouTubeViewer`, поэтому профиль WebView2, вход в YouTube и настройки подключения сохраняются.

## Проверка

Сборка требует PowerShell 7 (`pwsh`) и при первом запуске скачивает закреплённый
релиз uBlock Origin Lite с GitHub, проверяя SHA256 из `adblock.lock.json`.
Архив кэшируется в `build/adblock/`; при несовпадении хэша сборка завершается
ошибкой. В установщик входят исходники расширения, правила, лицензия и
`THIRD-PARTY-NOTICES.md`. Для обновления правил нужен новый выпуск Viewer;
настройки VPN и маршрутизации блокировщик не меняет. Изменения на стороне
YouTube могут потребовать обновления фильтров, поэтому отсутствие любой рекламы
при любых условиях не гарантируется.

```powershell
dotnet run --project .\youtube_viewer\tests\YouTubeViewer.Tests.csproj --configuration Release
dotnet run --project .\youtube_viewer\tests\ui\YouTubeViewer.UiTests.csproj --configuration Release
dotnet run --project .\youtube_viewer\tests\ui\YouTubeViewer.UiTests.csproj --configuration Release -- --webview
dotnet run --project .\youtube_viewer\tests\ui\YouTubeViewer.UiTests.csproj --configuration Release -- --adblock
dotnet build .\youtube_viewer\YouTubeViewer.csproj --configuration Release
.\packaging\windows\build.ps1
```

Проверка `--webview` использует настоящий WebView2, отдельный профиль в `downloads/` и тестовые HTML-ответы без обращения к YouTube. Она проверяет восстановление семи вкладок, переключение, перенос живой страницы, тайм-аут и повтор загрузки, а также восстановление превью после ошибок и зависания при прокрутке ленты из 150 карточек. Тестовое окно открывается вне экрана без активации; пользовательский профиль не используется.

Для отдельной проверки реального YouTube через системное подключение используйте ту же команду с `--youtube` вместо `--webview`. Она открывает публичный поиск в изолированном профиле и сохраняет снимок страницы в каталог результатов теста.

Для проверки видео используйте `--playback-url "https://www.youtube.com/watch?v=VIDEO_ID"`
вместо `--webview`. Проверка без звука подтверждает декодированные кадры и продвижение
времени основного видео после 35 секунд; поиск и реклама не считаются успешным
воспроизведением. Пользовательский профиль и настройки не читаются.
В этом режиме можно добавить `--proxy-url "http://127.0.0.1:10809"` для проверки
явного прокси или `--disable-quic` для сравнения системного подключения без QUIC.
Эти параметры меняют только тестовый профиль. Сетевые ошибки выводятся по именам
хостов без cookies и подписанных адресов видеопотоков.
